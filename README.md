# Obstacle-Avoidning-System
Obstacle Avoiding System using Ultrasonic Sensor
Obstacle Avoiding System using Ultrasonic Sensor is an intelligent device which can automatically sense the obstacle in front of it and avoid them by turning itself. 

It   is capable of moving on its own in an unknown and unstructured environment. 

This system is equipped with software intelligence to sense its environment, detect obstacles in its path and move around an unknown environment overcoming the obstacles.
